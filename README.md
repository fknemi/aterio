# Aterio - Restaurant Website

A modern, responsive restaurant website built with **Next.js**, **Chakra UI**, and **TypeScript**. Aterio provides a beautiful user interface for restaurant browsing, reservation management, and customer engagement.

## Features

- **Responsive Design** - Mobile-first approach with beautiful UI components from Chakra UI
- **Dark/Light Mode** - App-wide theme switching for user preference
- **Restaurant Information** - Showcase menu, location, hours, and contact details
- **Reservation System** - Allow customers to book tables with date and time selection
- **User Authentication** - Secure login and signup with JWT tokens and bcrypt encryption
- **Calendar Integration** - Interactive calendar for selecting reservation dates
- **Type-Safe Development** - Built with TypeScript for better code reliability
- **Database Integration** - Prisma ORM for seamless database operations

## Tech Stack

### Frontend
- **Next.js** - React framework for production-ready web applications
- **React 18** - UI library for building interactive components
- **Chakra UI** - Component library with accessibility features
- **TypeScript** - Static typing for JavaScript
- **Framer Motion** - Animation library for smooth interactions
- **React Calendar** - Interactive calendar component

### Backend & Database
- **Prisma** - ORM for database access and migration
- **Node.js** - JavaScript runtime for server-side logic
- **JWT** - JSON Web Tokens for authentication
- **bcrypt** - Password hashing for security

### Other Tools
- **Cookies Next** - Cookie management for persistent sessions
- **React Intersection Observer** - Performance optimization for lazy loading

## Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v14 or higher)
- **npm**, **yarn**, or **pnpm** package manager
- A database (PostgreSQL, MySQL, SQLite, or MongoDB)
